# Software Architecture

## Workflow
1. Inspect project context and conventions.
2. Identify inputs, constraints, dependencies and unknowns.
3. Follow project instructions and least-privilege policy.
4. Make focused, reviewable changes or produce the requested analysis.
5. Verify claims with actual evidence.
6. Report outputs, limitations, risks and next steps.

## Output
State what was inspected or changed, separate facts from assumptions, list checks actually performed, and flag missing information or approval requirements.
