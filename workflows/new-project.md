# New project workflow
1. Inspect workspace and existing conventions.
2. Discover goals, users, scope and constraints.
3. Create PRD, user journeys and acceptance criteria.
4. Propose architecture, data model, API boundaries and security model.
5. Select a profile and list missing skills/tools.
6. Present risks, milestones and approval points.
7. Implement a small vertical slice after approval.
8. Add tests, code review and security checks.
9. Verify staging before approved production release.
