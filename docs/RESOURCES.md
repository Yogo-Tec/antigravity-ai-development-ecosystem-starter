## Upstream adoption checklist
1. Verify repository owner and URL.
2. Read license and commercial-use terms.
3. Check recent activity, releases and security advisories.
4. Inspect install scripts and dependencies.
5. Test in a sandbox and pin a version/commit.
6. Record compatibility and local modifications.
